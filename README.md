# Практическая работа 1-5 - Реалезация 3D шутера

## Описание
Реалезация 3D шутера с использованием готовых ассетов.

## Цель
1. При помощи базовых знаний интерфейса Unity и языка программирования С#, реализовать передвижение персонажа.
2. При помощи базовых знаний устройства движка Unity и языка C#, создать камеру от первого лица и очки жизней.
3. Реализовать игровой объект при соприкосновении с которым восполняется запас очков жизней.
4. Реализовать механику стрельбы и смены оружия.
5. При помощи аниматора реализовать переключения анимации на оружие.
