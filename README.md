# Практическая работа 10 - Порт на Android

## Описание
Реализация 2D рогалика с использованием готовых ассетов.

## Цель
1. Разработать 2D игру с главным меню, создать не менее трёх проходимых уровней.
2. Добавить интерфейс и адамптировать управление под мобильные платформы.
3. Портировать игру на мобильные платформы.
4. Донастроить все анимации, добавить декорации.
