# Практическая работа 6-9 - Реализация 2D рогалика

## Описание
Реализация 2D рогалика с использованием готовых ассетов.

## Цель
1. При помощи встроенных инструментов Unity, реализовать пользовательский интерфейс игры.
2. Создать 2D уровень применяя все полученные на лекции навыки.
3. Создать и добавить анимации для всех объектов, для которых предпологается анимация.
4. Добавить на уровень задний фон с параллакс эффектом, закреплённым за основной камерой. Добавить чекпоинты, возраждающие персонажа после смерти.
